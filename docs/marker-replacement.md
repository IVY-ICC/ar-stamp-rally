# マーカー差し替え手順

## 1. all.mind を作る
1. `markers/` の画像9枚(印刷用と同じもの)を用意する。
2. https://hiukim.github.io/mind-ar-js-doc/tools/compile を開き、9枚をまとめて追加して Start。
3. ダウンロードされた `targets.mind` を **`all.mind` に名前を変えて `ar/` に置く**。
   (ブラウザのコンパイラはカメラ読み取りの特徴点だけを作る。1ファイルに9枚分が入る。)

## 2. 順番を合わせる(最重要)
コンパイラの画面に表示された画像の並びが targetIndex 0,1,2…になる。
その順にスポット番号を `js/config.js` の `MARKER_ORDER` に書く。
(現在は ⑦⑧⑨①②③④⑤⑥ の順)
確認:公開後に `debug.html` を開いてマーカーを映すと「検出 targetIndex=N」と出るので、
想定のスポットと合っているか9枚すべて確認する。

## 3. 反映
`ar/all.mind` と `js/config.js` は **同時に** push する(片方だけだと順番がずれる)。
`index.html` の `all.mind?v=…` の数字を変えると、古いキャッシュを避けられる。
反映は約10分かかる。必ずスマホ実機で9枚すべて読み取って確認する。

## 印刷のコツ
A4 縦・マット紙(光沢紙は反射で読めない)。白ベースの画像を余白を付けて印刷し、明るい場所に貼る。
