# トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| 「読み取りデータが見つかりません」 | `ar/all.mind` が無い/パスが違う。`ar/` に置いて push。 |
| マーカーを映すと輪っかが回り続ける | 問題ページ側が古い。`spots/` が最新か確認し、`index.html` の `?v=` を変える。 |
| マーカーと違う問題が出る | 順番ずれ。`debug.html` で targetIndex を確認し `MARKER_ORDER` を直す。 |
| マーカーを全く読み取らない | アプリ内ブラウザ/カメラ権限/反射。Safari・Chrome で開き、マット紙・明るい場所で。 |
| 更新したのに変わらない | Pages反映待ち(約10分)・キャッシュ。URLに `?v=2` などを付けて開く。 |
| 記録を消したい | `reset.html` を開く(係の人用QRの行き先)。そのスマホの記録が消え「スタートへ戻る」が出る。端末・ブラウザごとに保存されるので、遊んでいたブラウザで開くこと。 |
| 他の端末で記録が引き継がれない | 仕様。記録は各スマホ内のみ。 |

困ったらまず `debug.html` を開き、all.mind の取得状況と検出番号を見る。
